# CytexLab Platform - Documentation

**Файлы:** Platform.hpp, Placement.hpp, UTF.hpp, Mem.hpp  
**Модуль:** Core  
**Зависимости:** Отсутствуют  

> [!WARNING]
> Платформа создает, собирает, поддерживает и существует **исключительно** для AMD64 (x86-64)

> [!CAUTION]
> При попытке сборки для i686 (x86-32) платформа проявляет UB (Неопределенное поведение), так как не создавалась для этого
> При успешной сборке могут возникнуть опасные моменты с указателями и прочими платформа-зависимыми вещами

> [!NOTE]
> Платформа создает на компиляторе LLVM. Поддержки других компиляторов нет, но возможна в будущем

**Дополнительные типы:**

> [!WARNING]
> В платформе тип `BOOL` является алиасом типа `UINT8` (`uint8_t`) и имеет размер 1 байта  
> В Win32 API тип `BOOL` интерпретируется как `INT32`. Платформа при необходимости автоматически преобразует тип  
> Данное преобразование не работает для **ручного** вызова функций Win32 API  


| Тип    | Алиас   | Размер | Значение                                                           |
|--------|---------|--------|--------------------------------------------------------------------|
| `BOOL` | uint8_t | 1 байт | Логическое значение. Принимает значение 0 (`FALSE`) или 1 (`TRUE`) |

> [!TIP]
> Дополнительные типы также поддерживают указатели по той же конструкции, что и базовые типы  
> Например: `LPBOOL` или `LPCBOOL`

## Placement.hpp

### Функции

```cpp
LPVOID operator new(UINT64 size, LPVOID mem)
```
**Параметры:**  

| Параметр | Тип      | Назначение                                                   |
|----------|----------|--------------------------------------------------------------|
| `size`   | `UINT64` | Размер объекта или структуры в байтах                        |
| `mem`    | `LPVOID` | Указатель на **выделенную** память для объекта или структуры |

**Возвращаемое значение:** Указатель на сконструированный объект (равен mem, но приведён к типу создаваемого объекта)

> [!NOTE]
> Данная функция предназначена для вызова конструктора классов и структур

> [!WARNING]
> Память **необходимо** освободить через *сторонние* функции (см. документацию)

**Пример:**

```cpp
class SomeClass
{
private:
    UINT8 SomeVar1, SomeVar2;
};

LPVOID mem = Allocate(sizeof(SomeClass));
SomeClass* object = new (mem) SomeClass();
// Работа с объектом
Free(mem);
```

## Platform.hpp

### Типы

**Базовые типы:**

| Тип    | Размер  | Алиас    | Значение                      |
|--------|---------|----------|-------------------------------|
| UINT8  | 1 байт  | uint8_t  | Целочисленный беззнаковый тип |
| UINT16 | 2 байта | uint16_t | Целочисленный беззнаковый тип |
| UINT32 | 4 байта | uint32_t | Целочисленный беззнаковый тип |
| UINT64 | 8 байт  | uint64_t | Целочисленный беззнаковый тип |
| INT8   | 1 байт  | int8_t   | Целочисленный знаковый тип    |
| INT16  | 2 байта | int16_t  | Целочисленный знаковый тип    |
| INT32  | 4 байта | int32_t  | Целочисленный знаковый тип    |
| INT64  | 8 байт  | int64_t  | Целочисленный знаковый тип    |

**Указатели:**  

Префикс **LP** перед типом данных указывает на то, что данный тип является указателем
Префикс **LPC** означает тоже что и **LP**, только добавляет константность указателю

| Тип       | На кого | Значение                                        |
|-----------|---------|-------------------------------------------------|
| LPUINT8   | UINT8   | Целочисленный беззнаковый указатель             |
| LPUINT16  | UINT16  | Целочисленный беззнаковый указатель             |
| LPUINT32  | UINT32  | Целочисленный беззнаковый указатель             |
| LPUINT64  | UINT64  | Целочисленный беззнаковый указатель             |
| LPINT8    | INT8    | Целочисленный знаковый указатель                |
| LPINT16   | INT16   | Целочисленный знаковый указатель                |
| LPINT32   | INT32   | Целочисленный знаковый указатель                |
| LPINT64   | INT64   | Целочисленный знаковый указатель                |
| LPCUINT8  | UINT8   | Константный целочисленный беззнаковый указатель |
| LPCUINT16 | UINT16  | Константный целочисленный беззнаковый указатель |
| LPCUINT32 | UINT32  | Константный целочисленный беззнаковый указатель |
| LPCUINT64 | UINT64  | Константный целочисленный беззнаковый указатель |
| LPCINT8   | INT8    | Константный целочисленный знаковый указатель    |
| LPCINT16  | INT16   | Константный целочисленный знаковый указатель    |
| LPCINT32  | INT32   | Константный целочисленный знаковый указатель    |
| LPCINT64  | INT64   | Константный целочисленный знаковый указатель    |

**Символы и строки:**  

> [!IMPORTANT]
> В платформе используется кодировка UTF-32, остальные кодировки используются по крайней необходимости

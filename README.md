## 📖 Обзор
CytexLab Platform является Open Source платформой для разработки программ и приложений на C++ без использования CRT (C RunTime) и STL. Платформа предоставляет полную альтернативу базовым функциями и классам CRT, STL своими функциями и классами. Исполняемые файлы созданные при помощи CytexLab Platform имеют очень маленький размер:

|Утилита| Размер        |
|---|---------------|
|STL+CRT| 150-300 КБайт |
|CRT| 150 КБайт     |
|CytexLab Platform| 30-50 КБайт   |

## 🔥 Возможности
CytexLab Platform предоставляет все необходимые функции и классы для написания консольных многопоточных программ под Windows:

1. Работа с системой: ISystem, WinFabric
2. Работа с консолью: IConsole
3. Работа с файлами: IFile
4. Работа с потоками: IThread, IMutex
5. Работа с трубами: IPipe
6. Работа с динамической расширяемой памятью (аллакатор): IAllacator
7. Работа с процессами

## ⚙️ Фичи
CytexLab Platform использует в своих недрах кодировку UTF-32 для кодирования строк, также предоставляет функции для преобразования как отедльных символов, так и целых строк в UTF-8, UTF-16
Также, платформа предоставляет удобною возможность писать в файлы и консоль не задумываясь про кодировку, даёт писать как и в UTF-32, так и бинарные данные
Платформа предоставляет слой абстракции, благодаря код становится независимым от конкретной операционной системы, даёт уверенность разработчику, что код не будет работать как надо на другой ОС
